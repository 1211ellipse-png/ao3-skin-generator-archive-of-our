使用说明

  1. 选内容。在首页选择内容类型，进入后用“外观 / 内容结构”选择具体模板。
  2. 更换正文内容。在“1 写内容”里，把“演示文字”替换成正文；不需要的称呼、署名等可以留空。聊天可以粘贴整段对话再拆解。
  3. 调样式，选择动效。在“2 调样式”里选配色，需要时再微调字体与布局。“阅读方式”即是动效，注意，部分动效没有在红白里试验过，可能无法成功。（ps：样式可以更换配色，也可以使用网站自带的配色）
  4. 试读。修改后预览会自动更新。
  5. 复制两份代码。按输出区的①②顺序粘贴到 AO3，最后用 AO3 的 Preview 检查。
动效都有什么？
  • 阅后即焚
  • 翻到下一页
  • 擦除已读文字
  • 故障错位后消失

用于短文本，共最多 300 字，称呼、标题与署名也计入/

这四项都是单次点击近似，刷新后可以重读。

其他动效还包括展开、逐行或逐字显现、辨认模糊字迹等适配方式。

六类内容怎么选？
  • 捡手机体：分为聊天气泡、角色台词
  • 信件、手稿：普通信纸 / 日记、拆信与折信（有简单的信纸滑动的动效）、备忘录、手稿与旁批。
  • 仿社交媒体：推特体、朋友圈、消息与通知。
  • 档案与记录：档案卡、档案夹页、逐层线索、路线札记、报纸剪报。
  • 正文排版：正文段落、整篇配色、正文与脚注、章节分组。
  • 照片与音乐：照片背面、音乐播放器。播放器用于模拟阅读场景，不播放真实音频。

切换外观后先检查预览。同类可兼容的正文会带入，专用字段各自保存；需要时使用“撤销外观切换”。歌单、乐评、回复、旁批等补充内容，勾选“添加…”后才会导出；取消勾选会保留输入。

预览空白、效果不动或无法复制怎么办？
  • 出现红色提示：先修正提示中的内容、格式或长度。此时预览可能保留上一次有效结果，复制会暂停。
  • 效果没有动：先取消“不看皮肤，只看文字”，确认变化节奏不是“直接呈现”，再点击预览中的阅读提示语。已经触发的单次效果，可用“重新试读”重置预览。
  • 预览始终空白：先保存草稿，再刷新或用新版 Chrome / Edge 重新打开；选择一个内容类型，并确认已填写正文。若提示“预览未加载”，按页面提示重新打开文件。
  • 手机看不到预览：点击“查看预览”；“切换窄屏”仅用于模拟正文宽度。
  • AO3 显示不同：检查是否选中了对应的 Work Skin、是否更新了两份代码、是否关闭了作者样式。悬停效果在触屏上不可靠，重要内容应保留可直接阅读的版本。
已经会 HTML / CSS，怎样自由编写？

首页点击“我会代码：自由编写”，或在编辑器的“草稿与更多”中选择“编辑 HTML / CSS”，将当前模板结果转入代码编辑。这里只编辑用于 AO3 的 HTML 与 CSS，不支持读者端 JavaScript。

正文通过 class 连接样式；不要使用 id、style 属性、脚本、事件、input 或嵌入的 style / iframe。CSS 建议使用以点开头的类选择器，例如 .wsk-text，预览会模拟 AO3 添加作用范围。出现红色警告时按提示修正，再复制输出。预览不加载远程图片等外部资源。
