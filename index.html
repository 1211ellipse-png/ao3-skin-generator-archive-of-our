在哪里粘贴？

① AO3 → Skins → My Work Skins → Create Work Skin。粘贴 CSS，点 Submit。

② 发帖时选择刚创建的 Work Skin，正文切到 HTML 编辑器，再粘贴 HTML。

最后点 AO3 的 Preview 检查。

开源项目与使用说明

核查日期：2026-10-22。以下状态根据 GitHub 仓库、最近提交、README 和许可证判断；未归档不代表仍在持续维护，部署难度为代码结构判断，没有实际部署这些第三方项目。

项目维护迹象部署与可用功能本工具的处理
ao3-twitter-generator
MIT		未归档；最近提交 2026-05-14。近期维护频率有限。Angular 项目，需 Node/npm 构建；有 GitHub Pages 工作流，难度中等。支持动态、引用、回复、图片、计数和下载 HTML。改编其文本下载逻辑；新增独立编写的社交动态模板（引用、回复、计数），保留离线纯文字预览。
CodeJar
MIT		未归档；最近提交 2025-10-14，已有一年未提交。轻量编辑器，无运行时依赖。集成容易；支持缩进、括号补全、撤销重做，不是完整网站。复用缩进扫描函数并适配原生 textarea；并改编其历史记录与光标恢复逻辑。未引入整套编辑器。
ao3-theme-generator
MIT		未归档；最近提交 2026-06-14；README 明示正在重构。Vue/Vite 前端 + 服务端，完整部署较复杂；针对站点皮肤、分媒体 CSS，区别于作品皮肤。不直接合并站点 CSS 或服务器。本工具提供本地草稿文件与整篇作品配色。
ao3-workskin-generator
未发现许可证		未归档；最近提交 2026-04-20。gh-pages 分支是编译好的静态文件，静态托管容易。社交媒体作品皮肤生成。仅参考功能范围，未复制未授权源码；未发现便于改造的源项目结构。

本文件可离线打开：下载后用浏览器打开即可。需要上线时，可将它作为 index.html 放在静态托管服务中，不需要构建或服务器。网络图片在预览里不会加载；代码导出保留允许的地址。

复用位置、版本与完整许可证

文本下载：Anlanther/ao3-twitter-generator，提交 5fcd15680b9a261c8427ede72048fdfce3a3e1c3，src/app/twitter-card/twitter-card.ts。缩进扫描：antonmedv/codejar，提交 32f7a803cccb191ff10f550dc58403c6b2eb311e，codejar.ts 的 findPadding、recordHistory 与 handleUndoRedo（textarea 适配）。对话拆解、待确认审核、旁白与导入撤销为本工具自行实现。两项复用均作适配，未复制上游演示内容或外部资源。
